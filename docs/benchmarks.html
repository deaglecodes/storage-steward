Storage Steward

An agent skill (Claude Code, Codex, Cursor, Gemini CLI and more) that keeps agent leftovers off your disk while you work. These benchmarks measure three things: storage saved over 60 days of heavy agent use, what that cleanup costs in re-downloads and lost files, and how many tokens the skill saves when an agent does the cleanup.

Disk used by agent leftovers, day by day

60 simulated days of a heavy Claude Code + desktop app + Codex user, replayed on real files. Growth rates come from the GitHub reports and a real developer Mac's measured folders.

A 1 TB drive on day 60

The runaway scenario models background-task output that nothing caps (reported at 278–771 GB per session in anthropics/claude-code issues). This is the "my 1 TB Mac is full" complaint.

What each policy costs

Saving space is easy if you delete everything. The real question is how much you lose doing it. A cache miss means a package or build had to be downloaded or rebuilt again. A lost deliverable means a file the user made in a Cowork session got deleted.

How it saves space without costing speed or tokens

Prevent while working

The skill gives agents five habits: one scratch place, no unbounded background output, copy-on-write clones of node_modules for worktrees, a free-space check before writes over 1 GB, and streaming instead of saving intermediate files.

Hooks sweep, zero tokens

UserPromptSubmit prints only when disk is low. Stop and SessionEnd start a detached sweep, at most every 3 h. The agent never waits on it and never reads its output.

Second-chance eviction

macOS only updates a file's access time when it's older than the modification time. The sweep "arms" stale cache entries by setting that time back. Any later read moves it forward and the entry is kept. Entries still unread after 7 days are deleted.
